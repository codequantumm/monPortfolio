# Portfolio de Nora Hamida

Portfolio statique de testeuse logiciel, publié avec GitHub Pages. Le site utilise HTML, CSS et JavaScript natifs ; aucune étape de compilation n’est nécessaire.

## Structure

- `index.html` : contenu et structure de la page
- `assets/css/` : styles
- `assets/js/` : rendu des compétences et projets
- `assets/images/` : portrait et visuels des projets
- `data/` : données JSON affichées par le site

## Modifier le contenu

Modifiez `data/skills.json` pour les compétences et `data/projects.json` pour les projets. Les images de projets référencées dans ces données doivent être placées dans `assets/images/`.

## Déploiement

Dans les paramètres GitHub du dépôt, configurez GitHub Pages pour publier la branche `main` depuis la racine (`/`). Le site est statique et ne requiert pas de commande de build.
